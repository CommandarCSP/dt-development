# 운영 가이드 템플릿 (type: guide)

- 구역: **운영 가이드** · 제목: `[가이드] {할 일}` · 라벨: `doc-guide`
- 맨 위에 **공통 머리**를 둔다(TP-003 §2): `node "${CLAUDE_PLUGIN_ROOT}/scripts/wikiConfig.mjs" header --type guide …`가 만든다. 이 종류는 **검토일**이 있다(다음 검토 = 검토일 + `reviewMonths`).

## 절 (순서대로, 빈 절은 뺀다)

1. **언제 쓰나** — 이 절차가 필요한 상황 1~2줄
2. **준비물** — 권한·도구·환경 목록
3. **절차** — 번호 목록. 한 단계에 한 동작, 명령은 코드블록
4. **확인 방법** — 끝났는지 어떻게 아는가(명령·화면·로그)
5. **문제가 생기면** — 증상 → 원인 → 조치 표, 더 막히면 누구에게

## 소스
세션·git·사용자 메모. 설계 배경이 길어지면 설계 문서로 나누고 링크한다.
